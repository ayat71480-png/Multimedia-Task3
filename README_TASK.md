# MeetShell + Lab 3 Candidate Gathering starter

## Open and run
1. Extract this ZIP.
2. Open the extracted `MeetShell_Lab3_Starter` folder in VS Code.
3. In Terminal run `npm install`.
4. Run `npm run dev` and open the local URL.
5. In MeetShell, use **Open Candidate Panel** to switch to the Lab 3 panel.

## Task reminder
This is a starter made from your Lab 1 and Lab 3 files. Review and complete the TODO comments in `src/components/CandidatePanel.jsx` against the task PDF, especially gathering-state completion and effect cleanup/dependency requirements. Test none/stun/wrong on your own network, take your own screenshot as `screenshots/stun.png`, write your own answers in `answers.docx`/PDF, and commit/push to your Lab 1 repository before the deadline.

The `node_modules` and `dist` folders were excluded; install dependencies locally with `npm install`.
